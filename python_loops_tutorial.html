Introduction to Loops

What are Loops?

Loops allow us to repeat operations or calculations a specific number of times or until a condition is met. Python provides two main types of loops:

  • for loops - Iterate over a sequence of values
  • while loops - Repeat while a condition is true

For Loops Fundamentals

Basic Syntax

for variable in range(start, stop, step):
    # Code block to execute in each iteration
    print(variable)

Key Components

  • Loop Variable: The counter that changes in each iteration
  • range(): Generates a sequence of numbers
  • Indentation: All code inside the loop must be indented

Nested Loops and Control Structures

Nested For Loops

for i in range(3):
    for j in range(3):
        print(f'i={i}, j={j}')

Problem 5: Calculate π Using Series

Problem 5: Calculate π Using Series (10 terms)
Medium

Description:

Calculate an approximate value of π using the Leibniz series:

π = 4 × Σ((-1)ʲ / (2j + 1)) for j=0 to n-1

  • Use a for loop to calculate π using the first 10 terms
  • Output the counter value and approximate π for each iteration

Solution:

# Calculate π using series
pi_approx = 0

for j in range(10):

print(f'\nFinal: π ≈ {calculated_pi:.6f}')

Problem 6: Calculate π with Controllable Accuracy

Problem 6: π Series with Controllable Accuracy
Medium

Description:

Modify Problem 5 to create a function that allows control over the accuracy (number of terms used)

Solution:

import math

def calculate_pi_series(num_terms):
    """Calculate π using series with specified terms"""
    pi_approx = 0
    for j in range(num_terms):
        term = ((-1) ** j) / (2 * j + 1)
        pi_approx += term
    return 4 * pi_approx

# Test with different accuracies
for terms in [1, 10, 100, 500]:
    pi_value = calculate_pi_series(terms)
    error = abs(pi_value - math.pi)
    print(f'Terms: {terms:3d} | π ≈ {pi_value:.8f} | Error: {error:.8f}')

Output:

Terms: 100 | π ≈ 3.13159290 | Error: 0.00999975

Problem 8: Cubic Spline Surface Plot

Problem 8: Cubic Spline Surface Plot
Hard

Description:

Develop a surface plot of z = f(x)·f(y) where f is a piecewise cubic spline:

f(x) = (1/6)·(x+2)³            for -2 ≤ x ≤ -1
f(x) = -(2/3)·x²·(1+x/2)        for -1 < x ≤ 0
f(x) = -(2/3)·x²·(1-x/2)        for 0 < x ≤ 1
f(x) = (1/6)·(2-x)³            for 1 < x ≤ 2
f(x) = 0                              otherwise

Solution:

import numpy as np

def cubic_spline(x):
    if -2 <= x <= -1:
        return (1/6) * (x + 2) ** 3
    elif -1 < x <= 0:
        return -(2/3) * x**2 * (1 + x/2)
    elif 0 < x <= 1:
        return -(2/3) * x**2 * (1 - x/2)
    elif 1 < x <= 2:
        return (1/6) * (2 - x) ** 3
    else:
        return 0

x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)

Z = np.zeros_like(X)
for i in range(len(x)):
    for j in range(len(y)):
        Z[j, i] = cubic_spline(X[j, i]) * cubic_spline(Y[j, i])

Problem 9: Calculate sin(π/4) Using Taylor Series

Problem 9: sin(π/4) Using Taylor Series
Hard

Description:

Calculate sin(π/4) using the Taylor series expansion:

sin(θ) = Σ((-1)ʲ / (2j+1)!) × θ^(2j+1)

  • Use for loop to calculate sin(π/4) with adjustable accuracy
  • Use math.factorial() for factorial calculations

Solution:

import math

def calculate_sin_taylor(theta, num_terms):
    sin_approx = 0
    for j in range(num_terms):
        numerator = ((-1) ** j) * (theta ** (2*j + 1))
        denominator = math.factorial(2*j + 1)
        term = numerator / denominator
        sin_approx += term
    return sin_approx

theta = math.pi / 4

for n_terms in [1, 2, 3, 4, 5]:
    sin_value = calculate_sin_taylor(theta, n_terms)
    error = abs(sin_value - math.sin(theta))
    print(f'Terms: {n_terms} | sin ≈ {sin_value:.8f} | Error: {error:.8f}')

Problem 10: Count Prime Numbers

Problem 10: Count Prime Numbers Between 2 and 100
Hard

Description:

  • Count how many prime numbers exist between 2 and 100 (inclusive)
  • Use nested for loops
  • Use the break statement when a divisor is found
  • Print the total count of primes

Solution:

prime_count = 0

for num in range(2, 101):
    is_prime = True
    
    for divisor in range(2, int(num ** 0.5) + 1):
        if num % divisor == 0:
            is_prime = False
            break
    
    if is_prime:
        prime_count += 1
        print(f'{num} is prime')

print(f'\nTotal: {prime_count}')

Output:

3 is prime
5 is prime
...

Problem 11: Special Integer Search

Problem 11: Find Special Even Integer
Hard

Description:

Find the smallest even integer that:

  • Is divisible by 13 AND 16
  • Has a square root greater than 120
  • Use a for loop starting from 1
  • Print message: "The required number is:" followed by the number

Solution:

import math

found = False
num = 1

while not found:
    if (num % 2 == 0 and 
        num % 13 == 0 and 
        num % 16 == 0 and 
        math.sqrt(num) > 120):
        
        print(f'The required number is: {num}')
        found = True
    
    num += 1

The required number is: 30784

Summary and Best Practices

Best Practices for Loops

  • Always indent loop body: Python uses indentation to define scope
  • Use meaningful variable names: j, k for indices; value, sum for data
  • Be careful with range(): Remember it excludes the stop value
  • Test with small values first: Debug with range(3) before range(1000)
  • Use break wisely: Exit loops early when conditions are met
  • Avoid nested loops when possible: They have O(n²) complexity
  • Add print statements for debugging: Track counter and variable values

Common Mistakes to Avoid

  • ❌ Forgetting the colon (:) at the end of the for statement
  • ❌ Incorrect indentation - Python is whitespace-sensitive
  • ❌ Off-by-one errors with range()
  • ❌ Modifying list/array while iterating
  • ❌ Forgetting parentheses in complex expressions
  • ❌ Not initializing accumulators before loops
